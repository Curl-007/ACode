# 清洗深入问答

1. **多个规则命中同一行怎么计数？** 每条规则报命中数，另报涉及的不同记录数；变更表保留执行顺序。
2. **去重后如何保留冲突信息？** 将被合并记录的关键差异写入异常明细，不用简单丢弃覆盖。
3. **可以用模型填补缺失吗？** 可以作为经验证方案，但要防止信息泄漏，报告误差，并保留“是否填补”标记。
4. **如何处理单位混用？** 从来源、字段说明或值域识别；无法确认的记录不自动换算。
5. **跨月数据规则不同怎么办？** 按规则生效时间分段运行，在输出中保留适用版本。
6. **怎样验证清洗脚本可重复？** 固定输入、依赖版本与随机种子，重复运行并比较文件摘要与关键合计。
7. **敏感字段需要纠错怎么办？** 在批准环境内最小化处理；分析副本只保留完成任务所需的掩码或汇总值。
8. **业务方要求删除不利记录怎么办？** 拒绝选择性清洗，保留完整结果，并可按事先定义的合规规则给敏感性对比。
