# 遗留系统演进方法

优先级可按业务影响、变更频率、故障与安全风险、测试缺口和替代成本评分。不要用代码行数或技术年龄单独排序。

每个迁移切片必须有明确主数据源、兼容期、对账方式、回退点和旧路径删除条件。特征测试描述现有行为，不先假设现有行为正确。

## 切片格式

- 当前约束：用变更/事故/交付数据说明为什么现在处理。
- 行为护栏：哪些输入输出、错误和副作用不能变化。
- 迁移接缝（seam）：在哪个调用或数据边界截获流量。
- 新旧关系：主路径、影子路径、数据主源和兼容期限。
- 观测：一致率、错误率、延迟、流量占比与业务指标。
- 回退：如何切回，期间写入的数据如何处理。
- 删除条件：旧调用、旧数据、开关和兼容层何时删除。

迁移计划没有删除条件时，只是把旧系统变成了永久双系统。
