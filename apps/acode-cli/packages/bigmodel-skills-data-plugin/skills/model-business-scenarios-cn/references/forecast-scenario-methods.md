# 预测与情景方法

| 条件 | 首选方法 | 验证重点 |
|---|---|---|
| 业务驱动清楚、历史较少 | 驱动模型 | 等式、假设范围、结果勾稽 |
| 稳定时间序列、短期预测 | 季节基线、移动平均或指数平滑 | 时间留出回测、季节与漂移 |
| 多个可行动驱动 | 回归或分层驱动模型 | 共线性、未来信息泄漏、样本外误差 |
| 新业务无历史 | 类比范围 + 情景 | 类比可比性、假设透明度 |

误差至少报告 MAE 或与业务单位一致的绝对误差；使用百分比误差时注意实际值接近 0 会失真。回测失败时保留简单基线，不因模型复杂而优先采用。

常用骨架：订阅收入=`期初客户×续费率×客单价 + 分期新增×生效比例×客单价`；交易收入=`有效流量×转化率×频次×客单价`；人员容量=`需求量×处理时长÷(每人可用工时×目标利用率)`；盈亏平衡=`固定成本÷单位贡献毛利`。每个模型必须写时间粒度、单位及新增/流失发生时点。
