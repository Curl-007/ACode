# 目标客户开发方法

## 客户证据卡

字段：企业法定名称、产品可服务范围、匹配度 0～3 与依据、当前信号 0～3 与发生日、可触达性 0～3 与来源、负面条件、最强业务假设、待验证问题、数据复核日、停止联系状态。

评分不直接相加，以免掩盖硬排除项。产品无法交付、地区不服务、采购冻结或禁止联系先标为不进入触达；其余按匹配度、时机和可触达性分别排序。

同一公司有多条产品线时，先为每条产品线单独定义“可服务场景、必需条件、排除条件、典型角色和有效信号”，再生成对应客户证据卡。不要把高客单价企业软件的采购信号、低门槛 SaaS 的试用信号和渠道产品的伙伴条件混用；评分只在同一产品线或已经完成口径换算的分组内比较。

## 触达卡

字段：本次真实触发、与对方角色相关的影响假设、可证明的价值、一个验证问题、低摩擦下一步、渠道、发送人、发送时间、停止条件。不得写“关注贵司很久”之类无法证明的关系。

无回复时依次检查送达、角色匹配、信号新鲜度和价值假设。纠正后最多按组织规则继续，不跨渠道轰炸；明确拒绝或退订立即停止。
