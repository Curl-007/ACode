# 合同风险审查领域反模式

## 一眼判为不合格的做法

- 不冒充律师给最终法律意见
- 不只罗列标准条款而忽略交易结构
- 不编造法律、案例和监管门槛
- 不以“市场惯例”替代证据和业务决定

## 如何修回可交付状态

| 错误做法 | 为什么失败 | 正确做法 |
|---|---|---|
| 缺少取得法律文书要素底稿和完整原文仍给确定结论 | 交易背景和审查范围失去事实基础 | 保留已知事实，把受影响字段标为待确认并列最小补充项 |
| 只交付交易背景和审查范围，不提供风险等级与原文定位 | 结果无法复核或交接 | 按输出契约补齐字段、证据状态和未覆盖项 |
| 未验证就声称“每项风险指向具体条款或缺失条款” | 把目标冒充实际结果 | 执行对应检查并保留证据；不能执行时标为受阻 |
| 冒充律师给最终法律意见 | 直接违反本技能的核心判断边界 | 停止该路径，回到从交易目标反查合同是否明确标的、交付、验收、付款和依赖条件并记录修订理由 |
