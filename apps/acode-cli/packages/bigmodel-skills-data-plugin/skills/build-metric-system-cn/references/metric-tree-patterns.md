# 指标树模式

- 交易：有效需求 × 转化 × 单次价值；护栏关注退款、履约、毛利和投诉。
- 订阅：客户基数 × 留存 × 扩张；护栏关注服务成本、承诺和欠款。
- 内容：有效消费用户 × 价值行为频次；护栏关注低质曝光、举报和供给生态。
- 企业工具：活跃组织 × 核心流程完成；护栏关注席位虚增、权限和支持成本。

这些只是候选机制。先确认实际价值事件和当前决策，再选择、组合或舍弃。指标树不是组织架构图，也不是看板目录。

## 口径卡与变更记录

口径卡字段：正式名称/业务含义、公式与单位、对象/身份与去重、事件/状态、窗口/时区、纳入/排除、数据来源与延迟、下钻维度、业务/数据负责人、版本与生效日。

变更记录字段：原因、旧/新定义、影响的报表/目标/接口、历史处理、新旧双跑周期、抽样对账、批准人、生效日和旧版下线条件。
