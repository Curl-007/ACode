# 项目交付规划方法

## 工作包卡

字段：编号、可验收产物、非范围、负责人、验收人、完成证据、工期区间、前置编号、所需资源、关键假设。工作包应能由一名负责人解释完成，不把“持续沟通”当产物。

## 里程碑卡

字段：业务结果、进入条件、包含工作包、目标日期、估算日期、承诺日期、验收证据、决策人。三类日期不得混用；承诺日期必须由负责人和依赖方确认。

## 变更影响卡

记录变更原因、范围、关键路径天数、资源、预算、质量、收益、风险、备选方案、批准人和生效日期。无法算出影响时先做发现任务，不批准“日期不变”的无证据变更。

关键路径脚本输出的是基于输入依赖和工期的数学结果；资源冲突、日历、审批等待和返工风险仍要单独校正。
