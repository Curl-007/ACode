# 经营差异分析

经营诊断不是列一排涨跌指标，而是把最终偏差拆成能勾稽对平的驱动因素，说清哪个影响最大、哪些互相抵消、哪些只是线索。

## 建立经营等式

先选一条和业务对得上的等式，再拆差异：

- 交易收入 = 有效流量 × 购买转化率 × 客单价；
- 订阅收入 = 期初收入 + 新增 + 扩张 - 收缩 - 流失；
- 毛利 = 收入 - 销售成本，或销量 × 单位毛利；
- 利润 = 毛利 - 人员、营销、履约、研发及其他费用。

同一个问题，只留一条能解释结果的最小等式。先确认拿什么当基准——预算、预测、上期还是去年同期，再统一期间、币种、含税口径、退款和内部交易。比较基础不一致时，先拉齐成可比口径，不要把季节性或口径变化写成经营恶化。

口径互相冲突、又判定不了哪个对时，按两种口径分别给出区间或分支结果，标出差异来自哪里、该由谁确认；不能任选一版继续算。数据工具不可用时，用用户已经给出的数字把能手算的一级分解算完，公式保留在结果里；没读到的明细，不能说成已经处理过。

## 量化驱动贡献

优先用能勾稽到总差异的分解：

- 价格 × 数量：把总差异拆为量效应、价效应和必要的组合效应；
- 率 × 结构：分清是各分组自身表现在变，还是渠道、产品或客户的结构在迁移；
- 费用：区分人数、单价、使用量、合同固定项、时间错位和一次性事项；
- 新增、留存与扩张：区分新业务贡献、存量扩张、收缩和流失。

每项贡献都写成带正负号的金额或业务量。最后核对“基准值 + 所有贡献 = 实际值”；解释不了的残差单独留着，不能为了对平随手塞进“其他”。多产品或费用类问题，按当前业务的等式选分解方式，不把交易模型硬套给订阅或项目型业务。具体公式和费用桥按需读取[经营差异分解](references/variance-decomposition.md)；参考文件不可用时，就按正文等式做最小分解。

算出来的贡献只是算术上的来源，不能直接证明业务原因。促销、竞争、产品改版或团队动作，只有在时间、分组和对照证据支持时才能写成原因，否则写成待验证假设。

## 判断哪些偏差值得行动

同时看绝对金额、相对幅度、持续时间、是否偏离计划和是否会改变决策。不要照搬固定百分比阈值；大科目的小幅偏差可能比小科目的大幅偏差更重要。

把结论分成三类：可控且持续的驱动，需要行动；时间错位或一次性事项，需要修正预期；数据或口径出了问题，先把数据和口径改对，不能让业务团队为错误信号负责。

## 交付经营诊断

交付一张能勾稽对平的经营贡献桥：起点、正向驱动、负向驱动、终点和未解释残差。之后只写三类信息：最大贡献项和金额、有证据支持的业务解释、负责人可以去做或去验证的动作。

没有明细数据时，用用户明确给出的数字把能算的一级分解算出来，再列出继续往下拆最少还需要哪些字段。要预测未来或比较方案，转用“业务预测与方案测算”；要研究用户行为，转用“用户行为与产品分析”。
