# 只读数据层
2026-10-09 修改：移除生产管理凭证、迁移和管理界面示例。

先核验 SKILL.md 的租户和只读条件。连接仅在服务端凭证托管取得；前端不含连接串或数据库密钥。生产连接拒绝管理员身份，只允许指定视图、表和列。

优先读取获准 schema 导出；确需 introspection 时使用已锁定的本地 Prisma 命令和同一只读受限账号，不使用自动下载的 npx。不得扩大库表访问来解决 introspection 失败。

查询参数白名单化，使用参数化查询，不拼接原始用户 SQL。租户标识从已验证服务端身份取得；每次聚合、明细、缓存和导出均应用同一范围，缓存键包含租户和权限范围。增加查询超时、返回数量和资源限制。

指标先在脱敏样例核对：订单去重、退款净额、日期时区、空集合分母、NULL处理；数据不可用时返回未知/不可用状态，不用0掩盖权限或连接失败。

任何写库、迁移、授权修改和管理界面均不在本版范围。只读 SELECT 也可能调用有副作用函数，执行接口必须限制查询形态和函数，不能只按语句开头判断只读。
