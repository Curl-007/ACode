# API 变更兼容性审查输出契约

| 字段 | 必填 | 验证要求 |
|---|---:|---|
| 契约语义差异表 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 消费者影响矩阵 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 兼容性判定 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 分阶段迁移计划 | 是 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 监控与回滚门 | 条件必填 | 绑定对象、版本、证据位置和核验状态；条件不成立时写受阻材料，不编造内容 |
| 限制与未验证项 | 是 | 精确说明受阻范围及其对结论的影响 |
| 下一步 | 是 | 给出责任角色、输入、动作和完成信号 |

## 证据状态

- **已核验**：本轮实际读取或运行，记录位置与结果。
- **用户提供**：来自用户材料，未被独立工具验证。
- **推断**：由证据支持但仍需实验或责任人确认。
- **受阻**：工具、权限、环境或材料使验证无法继续。
- **未执行和未验证**：计划中的动作，不能写成已完成。

## 完成门

- [ ] 对象、版本、环境与范围可唯一定位。
- [ ] 契约语义差异表与消费者影响矩阵均有可复核证据。
- [ ] 正常、失败、权限或回滚路径按任务风险覆盖。
- [ ] 命令、测试或人工复核结果没有被计划文本替代。
- [ ] 敏感数据已脱敏，高影响动作已获授权或保持草稿。
