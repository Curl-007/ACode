# 最小事件模板
2026-10-09 修改：去除默认采集身份信息与第三方部署示例。

示例为设计资料，不自动上报：
| 事件 | 业务问题 | 最小字段 | 触发 | 接收方/地区 | 处理依据 | 保留/退出 |
|---|---|---|---|---|---|---|
| booking_submitted | 预约流程是否完成 | form_version、result_code | 服务端确认预约结果 | 待批准 | 待核实 | 待配置 |

不得把真实用户ID、邮箱、完整页面地址、表单自由文本直接添入示例。错误信息使用枚举码，不记录带个人内容的异常堆栈。幂等事件ID限必要的单次事件去重，不扩展为跨站身份跟踪。

转化率明确同一批次、分子、分母和时间窗；区分重复发送、重试与真实重复业务。离线校验列出期望条数、观察条数和差异；未收到真实事件不可声称已验证埋点工作。
