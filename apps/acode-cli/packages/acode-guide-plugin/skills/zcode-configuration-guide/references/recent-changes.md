# Recent changes: renamed and removed keys, paths, and commands

Newest first. This file is the second-priority source in the guide's doctrine: the live
Current Build section wins over it, and it wins over training data. Record an entry here
whenever a setting key, config path, command name, or event name is renamed or removed, so
answers can migrate users off stale names instead of repeating them.

## 2026-10 — guide rewrite wave (verified against the current checkout)

- **Config paths use `.acode`, not `.zcode`.** Older revisions of this guide told users to
  edit `~/.zcode/cli/config.json` and `<repo>/.zcode/config.json`. The build's actual paths
  are `~/.acode/cli/config.json` (user) and `<repo>/.acode/config.json` or `<repo>/acode.json`
  (workspace), with `<repo>/.agents/mcp.json` (top-level `mcpServers`) as a lowest-priority
  compatibility fallback. Any `.zcode` path in an older answer is wrong for this build.
- **MCP same-name precedence: workspace overwrites user.** Layers merge
  `system < user < project < session < env < cli < policy`, higher applied later and winning.
  Older revisions of this guide claimed "user beats workspace" for a same-named server — that
  is inverted for this build. The managed policy layer still only tightens, never widens.
- **Hook events: say which surface.** The config-file surface (`hooks.events.*`, strict
  schema, gated by `hooks.enabled`) accepts 7 event keys: SessionStart, UserPromptSubmit,
  PreToolUse, PermissionRequest, PostToolUse, PostToolUseFailure, Stop. The runtime contracts
  vocabulary is larger (17 names, including PostToolBatch, StopFailure, Pre/PostCompact,
  Pre/PostModelSwitch, SessionEnd, TaskCreated, TaskCompleted, CwdChanged). The old flat
  claim "exactly seven events are supported" conflated the two surfaces and is retired.
- **`dynamic-workflows` skill single-sourced.** The stale copy that used to ship inside
  `acode-guide-plugin` was removed (2026-10-15); the bundled-skills package is now the only
  source, and `tests/plugin-registration-description-parity.test.mjs` fails if a duplicate
  returns.
- **Current Build live section added.** This skill now embeds the `{{ACODE_CURRENT_BUILD}}`
  placeholder; the Skill tool replaces it at invocation time with a snapshot generated by the
  running CLI (tools, skills, custom commands, agents, configured MCP servers, configured
  settings keys, version when wired). Subsections can read `unavailable this time` — that is
  a degraded collection, not a missing feature.
