# 命令中心项目搜索

## 产品规则

- 搜索弹窗在现有范围选项卡末尾新增“项目”，中英文均提供文案。
- 数据范围是当前窗口左侧已有的项目，不扫描磁盘，不搜索尚未加入侧栏的目录。
- 输入去除首尾空白后，对项目显示名称或完整路径执行不区分大小写的包含匹配；任一字段命中即可。空输入显示全部项目，保持侧栏顺序。
- 结果显示项目名称和完整路径（过长截断，悬停可查看完整内容）。
- “全部”搜索有关键词时也展示项目结果，默认展示前三条，可展开全部；专用“项目”范围展示所有匹配项。
- 点击或键盘选择项目后，通过现有 activateTab 激活已存在的项目并关闭弹窗，不新增项目、不新建任务、不打开系统文件管理器。
- 项目搜索历史使用 projects 范围，复用现有历史持久化；旧历史无需迁移。

## 状态与边界

- tabStore 是项目列表及激活状态的唯一所有者；App 提供 workspaceTabs 和既有 activateTab 命令。
- CommandCenterDialog 拥有搜索词、范围及展开状态；结果为 workspaceTabs 的派生数据，不维护项目副本。
- 身份去重遵循 workspaceIdentity?.trim() || workspacePath，远程同路径项目保持隔离。
- 所有匹配均为同步 UI 计算，无新增服务调用或异步请求，桌面与 Web 共用实现。

```text
输入/选择范围 → CommandCenterDialog 派生匹配结果
选择项目 → 记录 projects 搜索历史 → App.activateTab(id) → tabStore 激活 → 关闭弹窗
```

## 验收场景

1. 打开搜索，看到“项目”选项卡；空输入切到该范围显示左侧已有项目。
2. 输入项目名称的部分字符，大小写不同仍能匹配。
3. 输入项目完整路径中的目录片段，大小写不同仍能匹配；内部空格保留为包含查询的一部分。
4. 无匹配时显示现有无结果提示；没有项目时显示项目空状态。
5. 鼠标点击或键盘回车选择结果后进入对应项目，弹窗关闭，没有新增任务或项目。
6. “全部”搜索可显示项目结果并展开；历史项可恢复项目范围。
7. 同路径不同远端身份项目不会被合并；窄屏选项卡可横向滚动，中英文及不同主题沿用现有样式。
