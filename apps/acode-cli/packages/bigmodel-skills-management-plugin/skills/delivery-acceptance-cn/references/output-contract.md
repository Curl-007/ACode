# 项目交付验收输出契约

## 目录

- 必填元数据
- 主体字段
- 状态枚举
- 完成门

## 必填元数据

| 字段 | 要求 |
|---|---|
| 对象与范围 | 唯一标识对象、时间范围、版本与排除项 |
| 数据快照 | 来源、查询时间、时区、过滤条件与失败项 |
| 证据状态 | 已核验、用户提供、推断、待确认或受阻 |
| 权限状态 | 只读、待审批、已授权或禁止执行 |

## 主体字段

- **验收范围与基准**：给出结论、证据、口径、责任角色或缺失原因。
- **需求追踪矩阵**：给出结论、证据、口径、责任角色或缺失原因。
- **证据清单与核验结果**：给出结论、证据、口径、责任角色或缺失原因。
- **遗留问题和豁免**：给出结论、证据、口径、责任角色或缺失原因。
- **运维与知识移交**：给出结论、证据、口径、责任角色或缺失原因。
- **验收结论建议与签署清单**：给出结论、证据、口径、责任角色或缺失原因。

## 领域字段补充

- 里程碑验收重点核对阶段交付物和准入条件；上线验收重点核对测试、发布、监控、回滚和数据安全；结项重点核对目标、遗留责任、资产与知识移交。
- 输出先列“关键阻断项与偏差摘要”，再展开验收矩阵；监控、回滚、数据安全、法定资质等致命缺陷不得淹没在长清单中。
- 供应商主体资质可用企查查或国家企业信用信息公示系统核验；连接器未授权时提供人工查询入口模板，并记录查询主体、统一社会信用代码、查询时间、查询人角色、页面来源、登记状态和待补证据，不把未查询写成通过。

## 状态枚举

- **已核验**：来自正文、系统结果或可复算材料。
- **用户提供**：由用户给出但尚未独立核验。
- **推断**：有证据支持但不是直接事实。
- **待确认**：缺少会改变结论的材料或决定。
- **未配置**：所需连接器或凭据不存在。
- **受阻**：已经尝试调用但工具、权限或上游失败。

## 完成门

- [ ] 通过项有同版本证据。
- [ ] 未验证没有写成通过。
- [ ] 豁免有责任人和到期日。
- [ ] 签署权没有越界。
- [ ] 完成声明来自最终状态。
- [ ] 每项黄线动作都有授权人与执行前提。
- [ ] 每项未完成内容都有具体补采方式。
