## 证据状态

- **已核验**：本轮实际读取或运行，记录位置与结果。
- **用户提供**：来自用户材料，未被独立工具验证。
- **推断**：由证据支持但仍需实验或责任人确认。
- **受阻**：工具、权限、环境或材料使验证无法继续。
- **未执行和未验证**：计划中的动作，不能写成已完成。

## 完成门

- [ ] 对象、版本、环境与范围可唯一定位。
- [ ] 目标视口与首次失效点两侧均有记录。
- [ ] 真实 200% 缩放与等效窄视口代理明确区分。
- [ ] 长中文、连续标识、缺图和列表压力样本按组件风险覆盖。
- [ ] 窄屏修改回归桌面，页面级横向滚动和主要操作可达性有测量证据。
