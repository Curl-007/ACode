# 合同风险审查输出契约

| 字段 | 必填要求 |
|---|---|
| 交易背景和审查范围 | 说明对象、范围和依据；不得只写“已完成合同风险审查” |
| 风险等级与原文定位 | 给出风险等级与原文定位的实际内容、证据状态和未覆盖项 |
| 法律和业务影响 | 给出法律和业务影响的实际内容、证据状态和未覆盖项 |
| 修改或谈判选项 | 给出修改或谈判选项的实际内容、证据状态和未覆盖项 |
| 内部批准和补偿控制 | 给出内部批准和补偿控制的实际内容、证据状态和未覆盖项 |
| 律师复核及未决问题 | 给出律师复核及未决问题的实际内容、证据状态和未覆盖项 |

## 合同风险审查完成门

- [ ] 每项风险指向具体条款或缺失条款
- [ ] 风险等级同时考虑可能性和影响
- [ ] 建议可直接进入谈判或审批
- [ ] 事实、法律判断和商业偏好分开
- [ ] 重大结论有权威来源或律师复核标记
- [ ] 未执行和未验证的步骤没有被写成合同风险审查已经完成。
