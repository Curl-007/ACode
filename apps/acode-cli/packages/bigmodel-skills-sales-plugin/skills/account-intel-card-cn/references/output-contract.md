# 企业客户背景调查输出契约

## 目录

- 必填元数据
- 主体字段
- 状态枚举
- 完成门

## 必填元数据

| 字段 | 要求 |
|---|---|
| 对象与范围 | 唯一标识对象、时间范围、版本与排除项 |
| 数据快照 | 来源、查询时间、时区、过滤条件与失败项 |
| 证据状态 | 已核验、用户提供、推断、待确认或受阻 |
| 权限状态 | 只读、待审批、已授权或禁止执行 |

## 主体字段

- **主体识别与消歧**：给出结论、证据、口径、责任角色或缺失原因。
- **工商与股权快照**：给出结论、证据、口径、责任角色或缺失原因。
- **业务与近期动态**：给出结论、证据、口径、责任角色或缺失原因。
- **公开关键人地图**：给出结论、证据、口径、责任角色或缺失原因。
- **需求信号与切入假设**：给出结论、证据、口径、责任角色或缺失原因。
- **来源台账、置信度与缺口**：给出结论、证据、口径、责任角色或缺失原因。

## 领域字段补充

- 只有用户单一材料且没有外部正文或系统结果佐证时，关键事实只能标“用户提供”，不能标“已核验”。
- 企业字段优先映射为企业全称、统一社会信用代码、登记状态、法定代表人、股东、变更日期和来源记录号。

## 状态枚举

- **已核验**：来自正文、系统结果或可复算材料。
- **用户提供**：由用户给出但尚未独立核验。
- **推断**：有证据支持但不是直接事实。
- **待确认**：缺少会改变结论的材料或决定。
- **未配置**：所需连接器或凭据不存在。
- **受阻**：已经尝试调用但工具、权限或上游失败。

## 完成门

- [ ] 每个关键事实绑定来源和日期。
- [ ] 公司主体没有同名串线。
- [ ] 财务数字只来自法定披露或用户材料。
- [ ] 个人信息保持最小必要并脱敏。
- [ ] 推断没有伪装成事实。
- [ ] 每项黄线动作都有授权人与执行前提。
- [ ] 每项未完成内容都有具体补采方式。
