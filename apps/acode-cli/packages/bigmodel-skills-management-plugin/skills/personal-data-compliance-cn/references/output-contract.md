# 个人信息合规审查输出契约

| 字段 | 必填要求 |
|---|---|
| 处理活动和主体角色 | 说明对象、范围和依据；不得只写“已完成个人信息合规审查” |
| 字段、目的和合法性基础 | 给出字段、目的和合法性基础的实际内容、证据状态和未覆盖项 |
| 敏感信息专项检查 | 给出敏感信息专项检查的实际内容、证据状态和未覆盖项 |
| 委托共享与跨境路径 | 给出委托共享与跨境路径的实际内容、证据状态和未覆盖项 |
| 留存、权利和安全控制 | 给出留存、权利和安全控制的实际内容、证据状态和未覆盖项 |
| 差距、整改和律师复核项 | 给出差距、整改和律师复核项的实际内容、证据状态和未覆盖项 |

## 个人信息合规审查完成门

- [ ] 数据清单与真实系统流程一致
- [ ] 每项处理都有明确目的和最小范围
- [ ] 接收方、角色和合同责任清楚
- [ ] 保存、删除和权利响应可以执行
- [ ] 法规门槛来自检索日官方来源
- [ ] 未执行和未验证的步骤没有被写成个人信息合规审查已经完成。
