# 投诉处置决策表

## 升级触发

立即升级：人身或财产重大风险、个人信息事件、监管或媒体联系、群体性影响、持续错误扣费、明确法律函件。
管理升级：多次未解决、关键客户流失、跨部门争议、补偿超权限、预计无法按承诺完成。
正常处置：事实明确、政策覆盖、补救可在当前权限内完成。

## 权限检查

任何退款、补偿、延期、恢复、公开回复或删除动作都要确认对象、金额、批准人、生效时间和撤销可能。系统已执行与“准备执行”必须分开写。

## 沟通受阻

客户拒绝补充信息或暂时中断沟通时，保留已确认事实、止损动作、待确认项、专属负责人、下一次主动更新时间和恢复渠道。不得把客户情绪或不配合当作拒绝基本权益、关闭投诉或自行补齐事实的理由。涉及人身安全、重大财产风险或明确威胁时转入组织应急升级。

四张卡应映射到组织现有的工单字段、审批角色、服务时限和升级队列；没有系统时使用同字段的手工交接表，状态仍区分已执行、待批准、受阻和待客户确认。

## 关闭条件

止损完成；承诺有执行证据；客户收到明确结果；仍有分歧时已告知申诉或监管渠道；同类客户是否受影响已检查。
