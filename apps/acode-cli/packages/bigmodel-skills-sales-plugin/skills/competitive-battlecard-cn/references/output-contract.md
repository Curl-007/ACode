# 竞品对比与应对策略输出契约

## 目录

- 必填元数据
- 主体字段
- 状态枚举
- 完成门

## 必填元数据

| 字段 | 要求 |
|---|---|
| 对象与范围 | 唯一标识对象、时间范围、版本与排除项 |
| 数据快照 | 来源、查询时间、时区、过滤条件与失败项 |
| 证据状态 | 已核验、用户提供、推断、待确认或受阻 |
| 权限状态 | 只读、待审批、已授权或禁止执行 |

## 主体字段

- **比较范围与口径**：给出结论、证据、口径、责任角色或缺失原因。
- **能力与限制矩阵**：给出结论、证据、口径、责任角色或缺失原因。
- **中国生态与部署适配**：给出结论、证据、口径、责任角色或缺失原因。
- **典型赢单与不适用条件**：给出结论、证据、口径、责任角色或缺失原因。
- **异议回应建议**：给出结论、证据、口径、责任角色或缺失原因。
- **来源、日期与置信度**：给出结论、证据、口径、责任角色或缺失原因。

## 领域字段补充

- 采集公开资料前检查目标站点服务条款、robots 约束和访问频率；受限页面只记“不可核验”，不绕过限制。
- 国内协作产品按套餐、版本、部署、开放接口、数据驻留和服务支持六列比较，不能跨版本拼接。
- 用户授权材料按组织保留规则处置；交付只保留必要引用，不附原始敏感副本。

## 状态枚举

- **已核验**：来自正文、系统结果或可复算材料。
- **用户提供**：由用户给出但尚未独立核验。
- **推断**：有证据支持但不是直接事实。
- **待确认**：缺少会改变结论的材料或决定。
- **未配置**：所需连接器或凭据不存在。
- **受阻**：已经尝试调用但工具、权限或上游失败。

## 完成门

- [ ] 每个可争议差异有来源。
- [ ] 套餐与版本没有混用。
- [ ] 事实和销售建议分开。
- [ ] 不使用商业诋毁表述。
- [ ] 过期信息有显著提示。
- [ ] 每项黄线动作都有授权人与执行前提。
- [ ] 每项未完成内容都有具体补采方式。
