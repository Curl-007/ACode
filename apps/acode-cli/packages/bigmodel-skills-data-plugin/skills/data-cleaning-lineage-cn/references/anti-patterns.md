# 数据清洗反例

| 错误做法 | 会造成什么 | 修正方法 |
|---|---|---|
| 所有空值填零 | 把未知或不适用变成真实业务数量 | 先分类缺失，只对有明确含义的情况填补 |
| 订单号重复就只留第一行 | 可能删除合法明细、后续状态或金额 | 确认粒度，写明保留优先级并检查冲突 |
| 超过三倍标准差就删除 | 真实大客户或活动峰值可能被抹掉 | 查业务原因，并比较处理前后关键结果 |
| 直接覆盖原工作簿 | 无法恢复和解释任何变化 | 保留只读原文件，输出新副本和变更表 |
| 合并表格后不看行数 | 多对多连接会放大数量和金额 | 合并前查唯一性，合并后对账匹配率和行数 |
| 只写“清洗完成” | 无法复跑，也无法知道删了什么 | 给规则、命中行数、示例行号、代码位置和对账 |

不得为了得到预期结论而选择性删除记录，也不得编造命中行数或清洗后的指标。
