- 许可构成（全集）：Apache-2.0 × 82、MIT × 43。**逐技能许可以 `skills/<技能目录>/LICENSE` 为准**；
  上游来源与平台改动登记见各技能目录内 `UPSTREAM.md` / `MODIFICATIONS.md` / `NOTICE.md`。

- 收录适配（重命名、frontmatter 清理）逐条登记在对应技能的 `MODIFICATIONS.md`，
