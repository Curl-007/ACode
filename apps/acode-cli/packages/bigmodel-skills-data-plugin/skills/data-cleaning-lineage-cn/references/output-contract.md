# 清洗交付格式

## 结果摘要

记录输入与输出文件、行列数、唯一业务对象数、关键金额或数量、实际执行时间和规则版本。

## 变更表

| 规则编号 | 字段 | 判断条件 | 动作 | 原因 | 命中行数 | 示例行号 | 影响记录数 | 可撤销 | 代码位置 |
|---|---|---|---|---|---:|---|---|---|---|

## 对账

- 输入行数 = 保留行数 + 删除行数；若新增行，单独说明生成数量。
- 输入关键合计 + 修正净额 - 删除净额 = 输出关键合计。
- 原缺失数 = 已填补数 + 仍缺失数 + 随删除记录减少的缺失数。
- 左表行数 + 一对多增加行数 = 连接后行数；另报未匹配键数。

## 完成检查

- [ ] 原文件保持不变，输出是独立副本。
- [ ] 每项变化都能对应规则与实际命中数量。
- [ ] 去重、删除、填补和连接没有无法解释的数量或金额差异。
- [ ] 冲突与解析失败记录保留在异常清单中。
- [ ] 同一输入和规则可重复生成相同结果。
- [ ] 敏感信息没有进入分析副本或示例。
- [ ] 未运行的规则标为“未执行”。
