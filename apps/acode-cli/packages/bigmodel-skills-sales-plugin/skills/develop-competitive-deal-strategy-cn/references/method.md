# 竞争交易策略方法

逐项检查可量化结果、经济决策人、评估标准、决策流程、采购流程、痛点、内部支持者和竞争。未知项必须有验证动作。

共同实施计划以客户动作作为阶段证据，覆盖技术、商务、法务、采购和上线。策略包含退出条件，避免沉没成本。

商机证据表：结果指标、经济决策人、评估标准、决策流程、采购/法务/安全流程、痛点、内部支持者、竞争状态；每项记录状态（已证实/推断/未知）、证据、负责人、验证动作和截止日。

权力图记录角色、影响力、立场、关心结果、关系负责人和下一验证动作，不收集无关个人信息。赢/胶着/输区表记录客户标准、我方证据、竞争证据、差距、可改变性和退出条件。

## 可填写交付卡

```text
交易判断：[可承诺赢单 / 胶着 / 当前不可承诺 / 应退出]
判断截至：[日期]

1. 客户结果：目标指标｜现状基线｜不改变后果｜证据/未知
2. 决策链：角色｜影响力｜立场｜关心结果｜关系负责人｜下一验证动作｜截止日
3. 评估区：客户标准｜我方证据｜竞争证据｜赢/胶着/输｜可改变动作｜退出条件
4. 资格缺口：未知项｜为什么影响成交｜验证对象｜动作｜负责人｜截止日
5. 共同计划：客户动作｜我方动作｜双方负责人｜完成证据｜日期｜前置依赖
6. 本周选择：继续投入什么｜停止什么｜最晚复核日｜触发退出的信号
```

证据未知时填写“未知 + 验证动作”，不得用中间分或行业传闻代填。只有客户确认的动作才能进入共同计划的客户责任栏。
