来自[智谱 BigModel 技能市场](https://open.bigmodel.cn/managed-agents/skills)的**研发**类技能合集
（平台离线快照，提取日期 2026-10-17；全集 125 技能按平台分类拆分为 8 个 ACode 官方插件，本包是其中之一）。

- 许可构成（全集）：Apache-2.0 × 82、MIT × 43。**逐技能许可以 `skills/<技能目录>/LICENSE` 为准**；
  上游来源与平台改动登记见各技能目录内 `UPSTREAM.md` / `MODIFICATIONS.md` / `NOTICE.md`。
- 默认关闭（`tier: "default_false"`）：在插件商店启用后，技能以 `bigmodel-skills-dev:<技能名>` 提供。
- 收录适配（重命名、frontmatter 清理）逐条登记在对应技能的 `MODIFICATIONS.md`，
  规则见 `apps/acode-cli/specs/bigmodel-skills-marketplace-plugins.md`。
