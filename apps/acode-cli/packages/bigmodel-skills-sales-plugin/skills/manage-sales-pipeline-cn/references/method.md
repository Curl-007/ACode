# 销售管道管理方法

## 单笔证据行

记录：唯一商机、客户、原币金额、换算金额与汇率日、阶段、阶段客户证据、最后客户事件、预计日期及历次漂移、经济决策人、采购流程、双方下一步、负责人、数据更新时间、可信度和退出条件。

## 预测分层

- 承诺：本期成交路径已由客户证据支持，关键角色、审批和双方日期明确。
- 最可能：历史与单笔证据支持，但仍有能够在本期关闭的具体缺口。
- 上行：本期可能推进，必须列出进入最可能所需的客户事件。
- 排除：无真实下一步、日期反复漂移或关键资格缺失且无修复计划。

管道速度 = 合格商机数 × 平均金额 × 赢单率 ÷ 销售周期。所有变量按一致客群和期间计算，分层后再看总量，避免混合平均掩盖结构变化。

每个干预写目标商机、要改变的证据、负责人、日期和失败后的退出动作。CRM 数据健康单列，不用“补字段”替代客户推进。
