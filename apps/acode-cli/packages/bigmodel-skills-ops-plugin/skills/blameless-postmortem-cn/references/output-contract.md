# 线上故障复盘与改进输出契约

## 目录

- 必填元数据
- 主体字段
- 状态枚举
- 完成门

## 必填元数据

| 字段 | 要求 |
|---|---|
| 对象与范围 | 唯一标识对象、时间范围、版本与排除项 |
| 数据快照 | 来源、查询时间、时区、过滤条件与失败项 |
| 证据状态 | 已核验、用户提供、推断、待确认或受阻 |
| 权限状态 | 只读、待审批、已授权或禁止执行 |

## 主体字段

- **执行摘要与影响**：给出结论、证据、口径、责任角色或缺失原因。
- **证据化时间线**：给出结论、证据、口径、责任角色或缺失原因。
- **触发、根因与扩大因素**：给出结论、证据、口径、责任角色或缺失原因。
- **响应评估**：给出结论、证据、口径、责任角色或缺失原因。
- **行动项与验收**：给出结论、证据、口径、责任角色或缺失原因。
- **经验、限制和对外口径**：给出结论、证据、口径、责任角色或缺失原因。

## 领域字段补充

- 五问分析字段为问题、直接原因证据、防线为何未阻止、为何未提前发现、系统性条件和可验证改进；证据不足时停止追问并标待确认。
- 代码发布证据可来自码云，指标日志可来自夜莺、Prometheus、Loki 或 ELK；未配置时只列补采计划。

## 状态枚举

- **已核验**：来自正文、系统结果或可复算材料。
- **用户提供**：由用户给出但尚未独立核验。
- **推断**：有证据支持但不是直接事实。
- **待确认**：缺少会改变结论的材料或决定。
- **未配置**：所需连接器或凭据不存在。
- **受阻**：已经尝试调用但工具、权限或上游失败。

## 完成门

- [ ] 复盘语言聚焦系统与条件。
- [ ] 影响数字有口径。
- [ ] 行动项可验收而非口号。
- [ ] 根因置信度与证据一致。
- [ ] 对外版已做信息分级。
- [ ] 每项黄线动作都有授权人与执行前提。
- [ ] 每项未完成内容都有具体补采方式。
