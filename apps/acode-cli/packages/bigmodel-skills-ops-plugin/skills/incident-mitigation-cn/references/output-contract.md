# 线上故障止损与协同输出契约

## 目录

- 必填元数据
- 主体字段
- 状态枚举
- 完成门

## 必填元数据

| 字段 | 要求 |
|---|---|
| 对象与范围 | 唯一标识对象、时间范围、版本与排除项 |
| 数据快照 | 来源、查询时间、时区、过滤条件与失败项 |
| 证据状态 | 已核验、用户提供、推断、待确认或受阻 |
| 权限状态 | 只读、待审批、已授权或禁止执行 |

## 主体字段

- **事件状态和影响**：给出结论、证据、口径、责任角色或缺失原因。
- **角色与沟通节奏**：给出结论、证据、口径、责任角色或缺失原因。
- **止损选项比较**：给出结论、证据、口径、责任角色或缺失原因。
- **动作卡与审批要求**：给出结论、证据、口径、责任角色或缺失原因。
- **观察和回退条件**：给出结论、证据、口径、责任角色或缺失原因。
- **内外部状态通报草稿**：给出结论、证据、口径、责任角色或缺失原因。

## 领域字段补充

- 紧急模式先交付等级、用户影响、前三个可逆止损动作、审批人、观察信号和回退条件；稳定后补全非关键元数据。
- 决策证据记录消息或审批记录编号、决定时间、选项、决定人角色和执行结果；口头建议不得写成已批准。
- 监控查询最小字段为服务、环境、区域、时间窗、当前值、基线和采样间隔；日志查询须脱敏并限制时间窗。

## 状态枚举

- **已核验**：来自正文、系统结果或可复算材料。
- **用户提供**：由用户给出但尚未独立核验。
- **推断**：有证据支持但不是直接事实。
- **待确认**：缺少会改变结论的材料或决定。
- **未配置**：所需连接器或凭据不存在。
- **受阻**：已经尝试调用但工具、权限或上游失败。

## 完成门

- [ ] 用户与数据安全优先。
- [ ] 每个动作可回退或说明不可回退。
- [ ] 审批人与执行者分开。
- [ ] 通报不猜测根因。
- [ ] 没有泄露凭证或内部敏感细节。
- [ ] 每项黄线动作都有授权人与执行前提。
- [ ] 每项未完成内容都有具体补采方式。
