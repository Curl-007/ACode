# 经营差异分解

## 价格与数量

设基准数量、价格为 `Q0、P0`，实际为 `Q1、P1`：

- 数量贡献：`(Q1-Q0)×P0`
- 价格贡献：`Q1×(P1-P0)`
- 两项相加应等于 `Q1×P1-Q0×P0`

存在产品、渠道或客户组合时逐分组计算，并把结构迁移与分组自身价量变化分开。不要同时使用多套分解顺序后选择更好看的答案；在报告中固定公式。

## 贡献桥验收

1. 起点和终点使用同一币种、期间和口径。
2. 每项贡献只出现一次，正负方向正确。
3. 贡献之和与总差异勾稽；舍入差异单列。
4. 算术贡献与业务原因使用不同措辞。

## 费用桥

人员费用可拆为 `(实际人数-基准人数)×基准人均成本 + 实际人数×(实际人均成本-基准人均成本)`；云资源、物流或客服费用可用相同的使用量×单位成本结构。合同固定项按新增/终止合同和生效期间单列，一次性事项单列，时间错位移回实际归属期。不同分解顺序会改变交互项归属，报告中固定一种并披露。

输入最少包含基准值、实际值、期间、币种/税口径和主要驱动。缺任一项时先输出已知差额与待补字段，不把残差解释成业务原因。
