# 客户问题排障手册

## 证据优先级

1. 原始错误和关联编号；
2. 同时间段服务端日志、指标与状态；
3. 可重复的操作步骤和环境差异；
4. 截图或转述，只能证明可见现象。

## 常见分层

- 身份：登录状态、租户、角色、授权范围；
- 客户端：版本、缓存、本地存储、浏览器扩展；
- 网络：DNS、代理、证书、地域和超时；
- 接口：请求参数、响应码、字段和幂等；
- 数据：延迟、同步任务、口径、权限过滤；
- 外部系统：回调、令牌有效期、限流和供应商状态。

## 升级给研发的最低字段

问题一句话、影响用户数、严重程度、发生时段、环境、最小复现、预期/实际、关联编号、已尝试动作、可用绕行、客户下一次更新时间。缺失字段标记“未取得”，不要编造。

## 假设—证据表

字段：假设、支持证据、反证、最小区分动作、结果 A 后续、结果 B 后续。每次只选择会改变下一步的一行；升级包另附当前责任层、仍缺的一个信号、是否可复现、证据链接与脱敏情况。
