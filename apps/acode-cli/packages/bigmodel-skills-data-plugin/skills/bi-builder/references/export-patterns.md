# 受控数据导出
2026-10-09 修改：替换为服务端权限与脱敏要求。

每次导出在服务端重查身份、租户、字段、行范围；不要直接导出页面曾加载的所有原始数据。默认只导出聚合数据，删除不必要身份字段，未知字段默认拒绝。

CSV 每个单元格按 CSV 规则转义，并处理首个非空白字符为 =、+、-、@ 或控制字符的文本，防止表格软件执行公式；真实数值与文本先按schema区分。只转义双引号不足以防公式注入。

产物写到租户专用受控存储，下载需鉴权并有过期策略，不生成匿名公开链接。文件名不包含客户身份、卡号或令牌。记录导出范围、数量、请求者、结果，不把完整明细写进日志。

图表截图或SVG同样可能含个人信息；检查标签、工具提示和隐藏数据。验收用两个隔离租户、被禁止字段、公式开头文本、空数据与大量数据测试，保留实际结果。

本包的 [bi-data-utils.mjs](../scripts/bi-data-utils.mjs) 提供可测试的白名单 CSV 编码和跨期日期映射纯函数；它不含平台鉴权，不能代替本页要求的服务端控制。
