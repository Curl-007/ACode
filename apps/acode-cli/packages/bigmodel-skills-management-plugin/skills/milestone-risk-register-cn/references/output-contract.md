# 项目里程碑与风险跟踪输出契约

## 目录

- 必填元数据
- 主体字段
- 状态枚举
- 完成门

## 必填元数据

| 字段 | 要求 |
|---|---|
| 对象与范围 | 唯一标识对象、时间范围、版本与排除项 |
| 数据快照 | 来源、查询时间、时区、过滤条件与失败项 |
| 证据状态 | 已核验、用户提供、推断、待确认或受阻 |
| 权限状态 | 只读、待审批、已授权或禁止执行 |

## 主体字段

- **里程碑基准表**：给出结论、证据、口径、责任角色或缺失原因。
- **风险与问题登记册**：给出结论、证据、口径、责任角色或缺失原因。
- **假设和依赖清单**：给出结论、证据、口径、责任角色或缺失原因。
- **风险矩阵与优先级**：给出结论、证据、口径、责任角色或缺失原因。
- **缓解、应急和升级建议**：给出结论、证据、口径、责任角色或缺失原因。
- **变更历史与复核日期**：给出结论、证据、口径、责任角色或缺失原因。

## 领域字段补充

- 风险必填描述、类别、概率、影响、紧迫度、触发条件、影响路径、负责人、预防、缓解、应急、复核日和最晚行动时间。
- 里程碑必填基准日期、前置条件、交付物、验收人和证据；矩阵必填概率轴、影响轴、分级口径和升级阈值。
- 定量矩阵与定性判断冲突时，以组织正式矩阵为主并保留专家判断；无矩阵时只用定性高/中/低。

## 状态枚举

- **已核验**：来自正文、系统结果或可复算材料。
- **用户提供**：由用户给出但尚未独立核验。
- **推断**：有证据支持但不是直接事实。
- **待确认**：缺少会改变结论的材料或决定。
- **未配置**：所需连接器或凭据不存在。
- **受阻**：已经尝试调用但工具、权限或上游失败。

## 完成门

- [ ] 风险和问题没有混淆。
- [ ] 每项有负责人或明确待分配。
- [ ] 概率影响分级口径可解释。
- [ ] 里程碑完成有验收证据。
- [ ] 升级没有未经确认发送。
- [ ] 每项黄线动作都有授权人与执行前提。
- [ ] 每项未完成内容都有具体补采方式。
