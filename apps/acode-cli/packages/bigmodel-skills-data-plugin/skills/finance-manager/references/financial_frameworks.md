# 收支口径与预算情景
2026-10-09 修改：移除固定比例等同财务健康的结论。

收入为 Income 正金额；支出为 Expense 负金额的绝对值；结余=收入-支出。收入为0时结余率记为不可计算，不伪造0%。最大支出按绝对值从大到小排序。日均支出按整个输入覆盖的自然日计算，空集合为0。

退款、内部转账、借贷本金和多币种不能不加区分混入收支。由用户确认分类与币种；不确定交易先列待核实，不能由脚本静默删去。汇总与原始账单总额对账后再解释趋势。

50/30/20等比例只是可选预算假设。用用户实际必要开支、负债支付和目标做情景比较，不给投资买卖建议、不保证收益、不由储蓄率给健康结论。金额精确到分；不支持混合币种自动换算。

examples/synthetic-transactions.csv 是完全虚构的测试样例。生成的HTML无外部资源，数据仍属报告内容，必须由平台控制存储访问和保留。
