# 销售管道健康检查输出契约

## 目录

- 必填元数据
- 主体字段
- 状态枚举
- 完成门

## 必填元数据

| 字段 | 要求 |
|---|---|
| 对象与范围 | 唯一标识对象、时间范围、版本与排除项 |
| 数据快照 | 来源、查询时间、时区、过滤条件与失败项 |
| 证据状态 | 已核验、用户提供、推断、待确认或受阻 |
| 权限状态 | 只读、待审批、已授权或禁止执行 |

## 主体字段

- **数据快照与口径**：给出结论、证据、口径、责任角色或缺失原因。
- **漏斗和覆盖摘要**：给出结论、证据、口径、责任角色或缺失原因。
- **高风险商机清单**：给出结论、证据、口径、责任角色或缺失原因。
- **数据质量问题**：给出结论、证据、口径、责任角色或缺失原因。
- **逐商机下一步建议**：给出结论、证据、口径、责任角色或缺失原因。
- **经理复核与更新清单**：给出结论、证据、口径、责任角色或缺失原因。

## 领域字段补充

- 阶段覆盖倍数=目标周期内有效管道金额÷目标缺口；金额统一币种，分母为零时标“不可计算”。
- 停滞、赢率和阶段时长只用组织阈值；未提供时按更新时间、活动、下一步和预计日期做相对排序。
- 通用字段容错映射：商机名/机会名→商机，客户/企业→客户，阶段/销售阶段→阶段，金额/预计金额→金额，预计日期/成交日→预计成交，跟进时间/更新时间→活动时间。

## 状态枚举

- **已核验**：来自正文、系统结果或可复算材料。
- **用户提供**：由用户给出但尚未独立核验。
- **推断**：有证据支持但不是直接事实。
- **待确认**：缺少会改变结论的材料或决定。
- **未配置**：所需连接器或凭据不存在。
- **受阻**：已经尝试调用但工具、权限或上游失败。

## 完成门

- [ ] 金额带币种与时间范围。
- [ ] 缺失值没有当作零。
- [ ] 组织没有提供阈值时不自创硬门槛。
- [ ] 预测事实与判断分开。
- [ ] 没有越权改状态。
- [ ] 每项黄线动作都有授权人与执行前提。
- [ ] 每项未完成内容都有具体补采方式。
