|---|---:|---|

## 证据状态

- **已核验**：本轮实际读取或运行，记录位置与结果。
- **用户提供**：来自用户材料，未被独立工具验证。
- **推断**：由证据支持但仍需实验或责任人确认。
- **受阻**：工具、权限、环境或材料使验证无法继续。
- **未执行和未验证**：计划中的动作，不能写成已完成。

## 完成门

- [ ] 对象、版本、环境与范围可唯一定位。
- [ ] 关键任务的键盘顺序、焦点进入、关闭和返回有轨迹记录。
- [ ] 名称、角色、状态、错误关联和动态播报按适用 WCAG 2.2 条款复核。
- [ ] 普通文字、大字、非文本控件与焦点指示使用相应对比度阈值。
- [ ] 200% 与 400% 缩放按关键任务复测；目标读屏未运行时保持未验证。
- [ ] WCAG 结果不冒充中国无障碍法规或标准的合规结论。
