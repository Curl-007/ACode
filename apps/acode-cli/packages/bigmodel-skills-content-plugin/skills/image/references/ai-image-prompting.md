# 图片创意和提示词
2026-10-09 修改：移除未经批准供应商的默认推荐，保留通用创意方法。

先读 SKILL.md 的调用与素材范围。提示词本身不授权上传。

用「主体 + 场景 + 视觉风格 + 光线 + 构图 + 尺寸」表达；例如：为自有茶叶品牌公众号设计封面，虚构茶园插画、晨光、左侧留出中文标题区域、横向画幅。品牌字体/标志仅用获准素材。

封面强调一个主体；商品图保持产品真实，不虚构包装或功效；产品界面应使用真实获准截图或明确标为概念稿。需要准确文字时先做背景，再以获准字体排版。

先给三种有差异的构图方向，再按选定方向细化。批量图复用色彩和版式，但逐张检查文字、人手、标志、边缘和标识。压缩与格式转换只使用已批准预装工具，保留必要生成标识和元数据。
