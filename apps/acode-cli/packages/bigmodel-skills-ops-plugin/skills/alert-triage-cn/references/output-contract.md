# 系统告警分级与处置输出契约

## 目录

- 必填元数据
- 主体字段
- 状态枚举
- 完成门

## 必填元数据

| 字段 | 要求 |
|---|---|
| 对象与范围 | 唯一标识对象、时间范围、版本与排除项 |
| 数据快照 | 来源、查询时间、时区、过滤条件与失败项 |
| 证据状态 | 已核验、用户提供、推断、待确认或受阻 |
| 权限状态 | 只读、待审批、已授权或禁止执行 |

## 主体字段

- **告警摘要与原始标识**：给出结论、证据、口径、责任角色或缺失原因。
- **合并关系和时间线**：给出结论、证据、口径、责任角色或缺失原因。
- **等级与判定依据**：给出结论、证据、口径、责任角色或缺失原因。
- **已知和未知影响面**：给出结论、证据、口径、责任角色或缺失原因。
- **补采证据与止损方向**：给出结论、证据、口径、责任角色或缺失原因。
- **升级条件和负责人建议**：给出结论、证据、口径、责任角色或缺失原因。

## 领域字段补充

- 关联变更必须输出时间偏差、影响范围、症状匹配度和反证，状态只能是“关联线索”，不得写成根因。
- 通用告警字段：alert_id/告警编号、service/服务名、env/环境、region/区域、starts_at/开始时间、metric/指标、value/当前值、threshold/阈值、labels/标签、status/状态。
- 合并至少同时比较服务或共同依赖、症状、环境、时间窗和区域；关键字段不同只关联不合并。

## 状态枚举

- **已核验**：来自正文、系统结果或可复算材料。
- **用户提供**：由用户给出但尚未独立核验。
- **推断**：有证据支持但不是直接事实。
- **待确认**：缺少会改变结论的材料或决定。
- **未配置**：所需连接器或凭据不存在。
- **受阻**：已经尝试调用但工具、权限或上游失败。

## 完成门

- [ ] 等级使用组织口径或注明临时。
- [ ] 告警风暴没有丢失原始证据。
- [ ] 关联变更没有直接写成根因。
- [ ] 运行时数据缺失标未配置。
- [ ] 没有自动执行高风险动作。
- [ ] 每项黄线动作都有授权人与执行前提。
- [ ] 每项未完成内容都有具体补采方式。
