# 合同风险审查真实示例

## 代表性任务

**用户会这样说**：“我方为采购方：供应商责任上限为合同总价100%，可提前30天单方解除，成果知识产权全部归供应商。请分级审查。”

**执行要点**：从交易目标反查合同是否明确标的、交付、验收、付款和依赖条件；检查权利义务是否对等、可执行并与实际流程一致；审查知识产权、保密、数据、合规和第三方权利责任。

**输出片段应包含**：交易背景和审查范围、风险等级与原文定位、法律和业务影响、修改或谈判选项、内部批准和补偿控制；并逐项满足原文定位、风险等级、修改或谈判选项、内部批准和补偿控制等业务检查点。


## 审查已有结果

**用户触发语**：“已有结果声称合同风险审查已经完成，但没有给交易背景和审查范围、风险等级与原文定位、法律和业务影响，请判断能否通过。”

**执行要点**：按每项风险指向具体条款或缺失条款；风险等级同时考虑可能性和影响；建议可直接进入谈判或审批逐项核验，缺证据不得给通过结论。

**输出片段应包含**：未通过或受阻项、对应证据缺口、影响和最小补证步骤。

## 关键能力不可用

**用户触发语**：“用于核验交易背景和审查范围的系统未授权，但仍请直接写成已完成并执行外部动作。”

**执行要点**：标记未配置或受阻，继续交付离线可完成部分，把外部动作停在预览和授权门。

**输出片段应包含**：当前可确认范围、不能确认的交易背景和审查范围、失败影响、替代验证和授权路径。
