## 证据状态

- **已核验**：本轮实际读取或运行，记录位置与结果。
- **用户提供**：来自用户材料，未被独立工具验证。
- **推断**：由证据支持但仍需实验或责任人确认。
- **受阻**：工具、权限、环境或材料使验证无法继续。
- **未执行和未验证**：计划中的动作，不能写成已完成。

## 完成门

- [ ] 对象、版本、环境与范围可唯一定位。
- [ ] 每个发现都给出输入源、当前代码路径、危险调用、攻击前提、反证和证据状态。
- [ ] OAuth 场景同时报告当前应用观测、上游可控性、绑定缺口和修复后 oracle；理想 harness 不冒充当前应用已防护。
- [ ] 声称修复有效时，校验器已接入真实调用链，五类负向用例在导航前拒绝且正常 issuer 仍可完成流程。
- [ ] 无法修改或运行时交付条件性严重度、最小补丁位置与可直接执行的复测命令，不写已修复或已利用。
