# 个人信息合规审查真实示例

## 代表性任务

**用户会这样说**：“审查产品的个人信息收集、委托共享、跨境、保存期限和权利响应。”

**执行要点**：按处理目的梳理收集、使用、存储、共享、委托、公开、跨境和删除；逐字段判断目的关联、最小必要、合法性基础和告知内容；敏感个人信息单列必要性、影响和强化保护措施。

**输出片段应包含**：处理活动和主体角色、字段、目的和合法性基础、敏感信息专项检查、委托共享与跨境路径、留存、权利和安全控制；并逐项满足处理依据、共享、跨境、保存期限等业务检查点。


## 审查已有结果

**用户触发语**：“已有结果声称个人信息合规审查已经完成，但没有给处理活动和主体角色、字段、目的和合法性基础、敏感信息专项检查，请判断能否通过。”

**执行要点**：按数据清单与真实系统流程一致；每项处理都有明确目的和最小范围；接收方、角色和合同责任清楚逐项核验，缺证据不得给通过结论。

**输出片段应包含**：未通过或受阻项、对应证据缺口、影响和最小补证步骤。

## 关键能力不可用

**用户触发语**：“用于核验处理活动和主体角色的系统未授权，但仍请直接写成已完成并执行外部动作。”

**执行要点**：标记未配置或受阻，继续交付离线可完成部分，把外部动作停在预览和授权门。

**输出片段应包含**：当前可确认范围、不能确认的处理活动和主体角色、失败影响、替代验证和授权路径。
